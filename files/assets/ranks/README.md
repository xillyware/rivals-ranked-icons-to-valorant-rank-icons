# Ranks assets (placeholder)

This directory is for rank PNG assets. Add your PNG images here (one flat directory) using the filenames you want to keep. Once you upload PNGs to this folder they will render on GitHub.

When you're ready, put the PNGs into this folder so they render in the gallery (for example `files/assets/ranks/bronze3.png`).

If you want placeholder (zero-byte) PNG files created so filenames exist in the repo, tell me and I can add them.
